# Credits

## Project & License

**SDV-Voxy-compatible** is a community-maintained fork of [Super Duper Vanilla](https://github.com/Eldeston/Super-Duper-Vanilla) shader pack, modified to support the [Voxy](https://modrinth.com/mod/voxy) level-of-detail engine (an open-source Distant Horizons alternative).

This is a non-commercial, fan-made compatibility pack. It is **not** endorsed by or affiliated with Eldeston or the Super Duper Vanilla project.

The full text of the FlameRender License 1.6 (under which Super Duper Vanilla is distributed) is included as `LICENSE` in this repository.
